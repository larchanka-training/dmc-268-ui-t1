# Разработка через тесты

Vitest и React Testing Library. Примеры — [`tests.md`](tests.md). Команды и слои —
[`rules/frontend.md`](../../rules/frontend.md).

Адаптировано из [`mattpocock/skills`](https://github.com/mattpocock/skills) (MIT),
`skills/engineering/tdd`.

## Где живёт тест

| Что тестируем                                    | Через что                                 | Где                                       |
| ------------------------------------------------ | ----------------------------------------- | ----------------------------------------- |
| Чистая логика: форматтеры, сборка диффа, фильтры | прямой вызов функции                      | рядом с модулем в `shared` или `entities` |
| Компонент                                        | RTL: рендер и действия пользователя       | рядом с компонентом                       |
| Фича целиком                                     | RTL плюс mock adapter данных              | в слое `features`                         |
| Интеграция слоёв                                 | рендер страницы с подменённым транспортом | в `pages`                                 |

Сетевой слой не мокается на уровне `fetch`: подменяется адаптер данных, у которого та же
граница, что и у будущего HTTP-клиента.

## Правила витка

- Красный до зелёного: падающий тест, затем ровно столько кода, чтобы он прошёл.
- Один срез за виток: тест → реализация → следующий виток, а не «сначала все тесты».
- Рефакторинг относится к ревью, не к циклу.
- Заменяй, не наслаивай: когда поведение переехало на уровень выше, тесты внутренних частей
  удаляются, а не остаются вторым слоем.

## Антипаттерны

- **Тест реализации** — селектор по классу, по имени компонента или проверка внутреннего
  состояния хука. Признак: ломается на рефакторинге без изменения поведения.
- **Тавтологический** — ожидаемое значение считается тем же выражением, что и в коде.
- **Снимок вместо утверждения** — снапшот, который обновляют не глядя, доказывает только то,
  что что-то отрендерилось.

Запрос по роли и тексту переживает переписывание разметки, запрос по `data-testid` — нет, но он
допустим, когда у элемента нет доступной роли.

```bash
pnpm run test && pnpm run typecheck && pnpm run lint
```
