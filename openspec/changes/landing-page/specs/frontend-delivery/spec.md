## ADDED Requirements

### Requirement: Приложение отдаётся под `/app`

Любой путь под `/app/` SHALL получать HTML приложения, чтобы глубокая ссылка открывалась после перезагрузки. `/app` без завершающего слеша SHALL перенаправляться на `/app/`. Dev-сервер SHALL отдавать пути под `/app/` приложению так же, как стенд.

#### Scenario: Глубокая ссылка в приложение

- **WHEN** пользователь перезагружает страницу на `/app/reviews/123`
- **THEN** ответ — HTML приложения, и открывается экран прогона

#### Scenario: Адрес без слеша

- **WHEN** клиент запрашивает `/app`
- **THEN** ответ — редирект на `/app/`

#### Scenario: Dev-сервер

- **WHEN** разработчик открывает `http://localhost:3000/app/repositories`
- **THEN** dev-сервер отдаёт приложение, а не лендинг

### Requirement: Вне `/app` — только статика

Путь вне `/app/`, `/api/` и `/assets/`, которому не соответствует файл статики, SHALL получать ответ `404` со статичной страницей и SHALL NOT получать HTML приложения.

#### Scenario: Несуществующая страница вне приложения

- **WHEN** клиент запрашивает `/nope`
- **THEN** ответ — `404` со статичной страницей и ссылками на лендинг и приложение

### Requirement: Документы загрузки не кешируются надолго

Лендинг, страница 404 и HTML приложения SHALL отдаваться без долговременного кеширования, как сейчас `index.html`.

#### Scenario: Новая версия лендинга

- **WHEN** после развёртывания пользователь открывает `/`
- **THEN** он получает новую версию лендинга, а не сохранённую с прошлого визита
