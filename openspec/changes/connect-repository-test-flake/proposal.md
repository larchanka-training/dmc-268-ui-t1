# Proposal

## Why

Тест `ConnectRepositoryPage › подключает репозиторий и обновляет список подключённых` время от времени падает на CI: не находит заголовок «Репозитории» после подключения. Так было в ui#23 на коммите, который этого теста не касается, а перезапуск прошёл.

Причина — задержки моков API. После клика мутация ждёт `delay(500)`, затем `onSuccess` дожидается повторной загрузки доступных репозиториев (`delay(350)`), и только потом происходит переход на `/repositories`. Из 1000 мс, которые `findBy` ждёт по умолчанию, 850 уходят на моки. На медленном раннере оставшегося запаса не хватает на рендер двух страниц.

## What Changes

- В `src/pages/ConnectRepositoryPage.test.tsx` модуль `repositoryApi` подменяется через `vi.mock`: те же функции отвечают сразу из `mockStore`, без задержек. Тест по-прежнему проверяет переход и обновление списка, но от скорости раннера больше не зависит.

## Impact

- Только тестовый файл. Код приложения, моки и требования спеки не меняются.
