## ADDED Requirements

### Requirement: Счётчики nginx для коллектора метрик

Образ интерфейса SHALL отдавать `stub_status` nginx по пути `/stub_status` на внутреннем порту 8081 в режимах HTTP и HTTPS. Порт 8081 SHALL NOT публиковаться на хост, поэтому снаружи `stub_status` недоступен.

#### Scenario: Коллектор снимает счётчики

- **WHEN** контейнер в сети стека запрашивает `http://dmc268-ui:8081/stub_status`
- **THEN** ответ содержит активные соединения и счётчики принятых соединений и запросов

#### Scenario: Снаружи счётчиков нет

- **WHEN** запрос идёт на `/stub_status` по публичному адресу интерфейса
- **THEN** он обрабатывается как обычный маршрут сайта, без счётчиков nginx
