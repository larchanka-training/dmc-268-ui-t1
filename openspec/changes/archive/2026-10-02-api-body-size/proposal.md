# Proposal

## Why

`client_max_body_size` в `nginx.conf` не задан, поэтому действует значение по умолчанию — 1 МБ. Через этот `nginx` идёт весь публичный трафик к API, включая вебхуки хостинга на `/api/v1/webhooks/{provider}`. GitHub шлёт вебхуки размером до 25 МБ; событие крупнее 1 МБ получит 413 от прокси и до бэкенда не дойдёт, а хостинг сочтёт доставку неудачной.

## What Changes

- В location `/api/` задаётся `client_max_body_size 25m` — потолок размера вебхука GitHub. Статика и остальные location остаются с ограничением по умолчанию: тела запросов им не нужны.

## Impact

- `nginx.conf`. Требования спеки не меняются: это параметр прокси, а не контракт доставки.
