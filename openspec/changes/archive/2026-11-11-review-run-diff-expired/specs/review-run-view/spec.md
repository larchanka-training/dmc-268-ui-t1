## ADDED Requirements

### Requirement: Дифф удалён по сроку хранения

Если у прогона `diff_expired_at` не `null`, экран SHALL не запрашивать `GET /api/v1/reviews/{id}/diff` и SHALL показывать на месте области изменений объяснение, что дифф удалён по сроку хранения, с датой удаления; замечания списком и «Ход прогона» SHALL оставаться на экране. Ответ `/diff` `410` с `code = DIFF_EXPIRED` SHALL показываться причиной «Дифф удалён по сроку хранения» с `detail` ответа, без «Повторить» и автоповтора.

#### Scenario: Прогон с удалённым диффом

- **WHEN** у прогона `diff_expired_at = 2026-10-21T03:00:00Z`
- **THEN** `GET /api/v1/reviews/{id}/diff` не запрашивается, на месте области изменений — «Дифф этого прогона удалён по сроку хранения 21.10.2026, 03:00 UTC», ниже замечания списком и «Ход прогона», «Повторить» нет

#### Scenario: Удалённый дифф у прогона без базовой ревизии

- **WHEN** у прогона `base_sha = null` и `diff_expired_at` не `null`
- **THEN** объяснение одно — про срок хранения, объяснения про базовую ревизию нет

#### Scenario: Дифф удалили, пока экран открыт

- **WHEN** прогон загружен с `diff_expired_at = null`, а `/diff` отвечает `410` с `code = DIFF_EXPIRED`
- **THEN** на месте области изменений — «Дифф удалён по сроку хранения» с `detail` ответа и без «Повторить», ниже замечания списком
- **AND** дифф запрошен один раз
