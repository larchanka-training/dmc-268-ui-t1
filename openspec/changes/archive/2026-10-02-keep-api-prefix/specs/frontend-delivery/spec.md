# Spec Delta

## MODIFIED Requirements

### Requirement: Браузер обращается к API по тому же адресу, что и к интерфейсу

Запросы интерфейса к API SHALL проходить через тот же адрес, по которому отдаётся сам интерфейс, и перенаправляться к API внутри серверного сетевого окружения.

Браузеру SHALL NOT требоваться второй адрес, и настройка межоригинных запросов SHALL NOT быть условием работоспособности.

Путь запроса SHALL доходить до API без изменений: префикс `/api` и версию ставит само приложение, и перенаправление SHALL NOT их срезать или переписывать.

#### Scenario: Запрос к API из интерфейса

- **WHEN** загруженный интерфейс обращается к API
- **THEN** запрос уходит на тот же адрес и достигает API, не покидая сервер

#### Scenario: Путь запроса сохраняется

- **WHEN** интерфейс запрашивает `/api/v1/reviews`
- **THEN** API получает запрос на `/api/v1/reviews`, а не на путь без префикса
