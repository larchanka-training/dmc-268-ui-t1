## Why

`GET /api/v1/reviews` в бэкенде реализован (api#103, api#125, коммит `ca1da11`): заглушки `501` у ручки больше нет, в контракте вместо неё `502 SCM_UNAVAILABLE` — GitHub не ответил, когда считался набор видимых репозиториев. Ветка вкладки «Ревью» для `501` стала мёртвым кодом.

## What Changes

- Контракт API — с `develop` бэкенда на `ca1da11` (`pnpm api:sync`).
- Состояние «Список прогонов ещё не реализован на сервере» удалено вместе с его проверкой.
- Ошибка загрузки списка, в том числе `502` от недоступного GitHub, показывается общим сообщением «Не удалось загрузить прогоны» с повтором; подписки на поток при этом нет.

## Capabilities

### Modified Capabilities

- `cabinet-reviews`: вместо отдельного состояния для `501` — общее состояние ошибки загрузки.

## Impact

- Код: `src/pages/reviews/ui/ReviewsPage.tsx`, `src/pages/reviews/model/reviewList.ts`, тест вкладки.
