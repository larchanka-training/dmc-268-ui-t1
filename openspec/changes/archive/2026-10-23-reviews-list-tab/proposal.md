# Proposal

## Why

В кабинете негде посмотреть прогоны ревью: экран одного прогона `/app/reviews/:id` открывается только по прямой ссылке, а `/app/reviews` уводит на «Обзор» (ui#43, ui#44). Бэкенд описал в контракте список `GET /api/v1/reviews` (пока заглушка `501 NOT_IMPLEMENTED`) и общий поток событий `GET /api/v1/events` (dmc-268-api-t1#103, #115). Фронт делает вкладку параллельно с реализацией ручки.

## What Changes

- Пункт «Ревью» в боковом меню и маршрут `/app/reviews` со списком прогонов; строка ведёт на экран прогона `/app/reviews/:id`.
- Таблица: репозиторий, PR (номер, заголовок, ссылка на PR у провайдера), статус (бейдж `RunStatusBadge`), источник запуска, начало, длительность, число замечаний.
- Поиск `q` и фильтры: «Все»/«Активные»/«Завершённые» (`active`), статусы, репозитории (несколько, `repository_id` повторяется), автор, период по дням UTC. Поиск, фильтры, страница и размер страницы — в URL; некорректный параметр — значение по умолчанию.
- Серверная пагинация `limit`/`offset` с номерами страниц ссылками (`useUrlPage`, `PageNav`) и «Найдено прогонов: N» по `total`.
- Обновления из общего потока одной подпиской вкладки: на первой странице без фильтров событие `run.*` накладывается на строку (upsert по `id`, побеждает больший `updated_at`), иначе страница перезапрашивается не чаще раза в секунду. На каждое `open` потока страница перезапрашивается.
- `501` от `GET /reviews` — состояние «Список прогонов ещё не реализован на сервере», без повторов запроса и без подписки на поток. Глобально `501` больше не повторяется как прочие `5xx`.
- Mock adapter отвечает на `GET /reviews` по контракту: около 30 прогонов двух репозиториев во всех статусах, фильтры, порядок, `total`. Прогон фикстуры и чужой прогон mock-потока в списке идут по тому же сценарию, что и события.
- Подписи статусов и источника запуска переезжают в `entities/review-run`, ими пользуются бейдж, фильтр и шапка экрана прогона.

**Не входит:** сортировка по колонкам (порядок задаёт бэкенд), ручной запуск ревью, общая подписка на поток для нескольких экранов.

## Capabilities

### New Capabilities

- `cabinet-reviews`: вкладка «Ревью» кабинета — список прогонов, фильтры и страница в URL, обновления из общего потока, состояние «не реализовано».

### Modified Capabilities

Нет.

## Impact

- Код: `src/pages/reviews`, `src/features/live-run-status` (`useRunListLiveUpdates`), `src/entities/review-run` (схема и запрос списка, `upsertRunListItem`, подписи), `src/app/router`, `src/widgets/app-shell`, `src/app/mocks`, `src/app/providers/queryClient.ts`.
- Контракт: синхронизирован на коммит PR бэкенда dmc-268-api-t1#115; перед мёржем — `pnpm api:sync` на коммит из `develop` бэкенда.
- Ветка отведена от `feat/run-screen-general-stream` (ui#52): вкладка пользуется той же схемой событий и тем же путём потока.
