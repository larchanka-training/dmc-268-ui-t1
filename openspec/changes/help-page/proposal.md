# Proposal

## Why

Задача [#97](https://github.com/larchanka-training/dmc-268-ui-t1/issues/97) (часть #95):
пользователь должен без нас понять, как подключить репозиторий и почему что-то не работает.
Нужна страница «Помощь» с шагами «Как начать» и вопросами и ответами, открытая и тем, кто ещё не
вошёл, — на неё ведёт страница входа.

## What Changes

- Страница помощи — статичный текст в коде фронта, без данных с сервера. Маршрут `/help`
  приложения, на стенде `/app/help`, вне проверки сессии: `RequireAuth` и шапка кабинета ей не
  нужны, у неё своя простая шапка с названием и переключателем темы.
- Разделы «Как начать» (шаги) и «Вопросы и ответы». У каждого вопроса постоянный якорь:
  `repo-missing`, `toggle-disabled`, `bot-silent`, `rerun`, `pause-review`, `remove-access`,
  `rules`, `merge-gate`, `who-sees`; у «Как начать» — `start`. Переход по адресу с `#якорь`
  прокручивает к вопросу.
- Ссылки: пункт «Помощь» в боковом меню кабинета и «Как это работает?» на странице входа.
- nginx отдаёт HTML приложения на `/app/help` без cookie сессии; остальные пути под `/app/`
  закрыты для гостя по-прежнему. Проверка маршрутов получила этот случай.

**Не входит**: подсказки на «Репозиториях» со ссылками на вопросы (#96), редирект `/help` на
`/app/help`, поиск по вопросам.

## Capabilities

### New Capabilities

- `cabinet-help`: публичная страница помощи с постоянными якорями и ссылками на неё.

### Modified Capabilities

- `frontend-delivery`: гость получает HTML приложения на `/app/help`.

## Impact

- Код: `src/pages/HelpPage.tsx`, `src/app/router/AppRouter.tsx`,
  `src/widgets/app-shell/ui/AppSidebar.tsx`, `login.html`, `src/styles/global.css`.
- Доставка: `nginx/site.conf`, `scripts/check-routes.sh`.
- Зависимости: новых нет.
