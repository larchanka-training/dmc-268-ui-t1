# Proposal

## Why

В интерфейсе пока только стартовый счётчик. Задача спринта для Инженера 2 — экран прогона ревью: метаданные, Diff Viewer в двух режимах и замечания AI прямо под строками, к которым они относятся. Definition of Done: страница показывает файлы диффа, а под строками с замечаниями корректно рендерятся раскрывающиеся карточки.

Эндпоинтов ревью в бэкенде ещё нет, поэтому экран строится на типизированном mock adapter с той же границей, что и будущий HTTP-клиент (FE-CON-06). Контракт данных взят из `FRONTEND_ARCHITECTURE.md` (PR #6) и сверен с бэкендом поле в поле.

## What Changes

- Появляется маршрут `/review-runs/:runId` со страницей `ReviewRunPage`; корень ведёт на демонстрационный прогон.
- `RunHeader`: название запроса на изменения, автор, ветки, вердикт и общая оценка, статус, коммит, запуск, время, длительность, модель, токены, причина сбоя, ссылка на источник.
- `ReviewSummary`: число замечаний по severity, опубликованные inline-комментарии, отброшенные валидацией, замечания без привязки к строке.
- `ReviewWorkspace`: список изменённых файлов и дифф одного выбранного файла в режиме «две колонки» или «одна колонка» с подсветкой синтаксиса.
- `FindingCard`: раскрывающаяся карточка замечания с severity, категорией, текстом, блоком предлагаемого кода и статусом публикации.
- Активный прогон обновляется polling-запросом до терминального статуса (FE-DEC-08).
- Слои по FSD; подключаются библиотеки, принятые в архитектуре: TanStack Query, Zustand, Zod, React Router, Headless UI, а также `@git-diff-view/react` для отображения диффа.
- **BREAKING** для спеки `testing`: smoke-тест счётчика `App` заменяется интеграционным тестом страницы — счётчика больше нет.

**Не входит:** список прогонов и PR, авторизация и поведение на `401`, `RunInspector` (ждёт FE-OPEN-10), фильтры замечаний, HTTP-клиент.

## Capabilities

### New Capabilities

- `review-run-view`: просмотр одного прогона ревью — метаданные, сводка, дифф файлов и inline-замечания AI.

### Modified Capabilities

- `testing`: smoke-тест `App` со счётчиком заменяется интеграционным тестом `ReviewRunPage`.

## Impact

- Код: `src/app`, `src/pages/review-run`, `src/widgets/{review-workspace,review-summary}`, `src/entities/{review-run,diff,review-finding}`, `src/shared/{api,lib,ui}`. Удалены `src/App.tsx` и `src/App.test.tsx`.
- Зависимости: `@git-diff-view/react`, `@tanstack/react-query`, `zustand`, `zod`, `react-router`, `@headlessui/react`.
- Бандл: просмотрщик диффа тянет подсветку всех языков highlight.js (~340 КБ gzip) и грузится отдельным чанком.
- Бэкенду: в DTO прогона фронтенд добавляет поля `merge_request` (название, автор, ветки), `verdict` и `score` — их нет в контракте §8.2, в моках они есть; нужно согласовать и реализовать.
- Бэкенду: эндпоинты `/files`, `/diff`, `/findings` из §9 архитектуры нужны для замены mock adapter; форма ответа `/findings` — `{ findings, published_comments }` — предположение фронтенда, её надо подтвердить.
