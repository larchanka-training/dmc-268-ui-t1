## ADDED Requirements

### Requirement: Стенд отдаётся по HTTP/2 и HTTP/3

Публичный адрес стенда SHALL отдавать интерфейс и API по HTTP/2 через TCP и по HTTP/3 через UDP на том же порту 443. Каждый ответ по HTTPS, включая `index.html` и статику, SHALL объявлять HTTP/3 заголовком `Alt-Svc`. Клиент, до которого UDP не доходит, SHALL получать интерфейс по HTTP/2. Развёртывание SHALL завершаться ошибкой, если после него стенд не отдаёт HTTP/2 по TCP или HTTP/3 по QUIC.

#### Scenario: Запрос по TCP

- **WHEN** клиент запрашивает `https://` адрес стенда по TCP
- **THEN** ответ приходит по HTTP/2
- **AND** в ответе есть заголовок `Alt-Svc` с `h3`

#### Scenario: Запрос по QUIC

- **WHEN** клиент запрашивает адрес стенда только по HTTP/3
- **THEN** ответ приходит по HTTP/3

#### Scenario: UDP закрыт

- **WHEN** у клиента закрыт UDP 443
- **THEN** клиент получает интерфейс по HTTP/2

#### Scenario: Стенд перестал отвечать по QUIC

- **WHEN** после развёртывания запрос только по HTTP/3 не получает ответа
- **THEN** развёртывание завершается ошибкой с указанием проверить UDP 443

### Requirement: Статика и ответы API сжимаются

Статика интерфейса SHALL отдаваться сжатой gzip клиенту, который присылает `Accept-Encoding: gzip`, и исходной — клиенту, который его не присылает. Ответы API в JSON SHALL сжиматься так же. Поток SSE (`text/event-stream`) SHALL NOT сжиматься, чтобы события не задерживались буферизацией. Сжатые ответы SHALL сохранять заголовки кэширования и SHALL содержать `Vary: Accept-Encoding`.

#### Scenario: Браузер поддерживает gzip

- **WHEN** клиент запрашивает JS-бандл с `Accept-Encoding: gzip`
- **THEN** ответ приходит с `Content-Encoding: gzip`, а после распаковки совпадает с исходным файлом
- **AND** `Cache-Control` ответа тот же, что у несжатого

#### Scenario: Клиент без gzip

- **WHEN** клиент запрашивает JS-бандл без `Accept-Encoding`
- **THEN** ответ приходит несжатым

#### Scenario: Поток событий не сжимается

- **WHEN** клиент подписывается на SSE с `Accept-Encoding: gzip`
- **THEN** ответ приходит без `Content-Encoding`, и каждое событие доходит сразу после отправки
