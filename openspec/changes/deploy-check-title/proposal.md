# Proposal

## Why

Деплой `develop` после мерджа #14 упал на проверке «по адресу отдаётся именно интерфейс», хотя стенд работает: HTTPS с сертификатом Let's Encrypt, редирект с HTTP, API под `/api/v1/`. Проверка ищет в ответе строку `DMC-268 UI` — старый `<title>` из стартового шаблона. #16 поменял заголовок на «DMC-268 — кабинет», и проверка перестала его узнавать.

## What Changes

- Проверка ищет имя проекта `DMC-268`, а не заголовок целиком. Заглушку nginx и чужой сервис она по-прежнему отличает от интерфейса.

## Capabilities

Поведение интерфейса и стенда не меняется, спеки не правятся (`skip_specs`).

## Impact

- `.github/workflows/deploy.yml`, шаг «Проверить, что по адресу отдаётся именно интерфейс».
